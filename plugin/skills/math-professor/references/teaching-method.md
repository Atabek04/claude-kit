# Teaching method

Loaded when starting a concept, diagnosing an error, choosing a hint or running a placement probe.

## Concept or procedure

| Kind | Examples | Opening move |
|---|---|---|
| Concept | span, rank, basis, limit, conditional probability | 5-8 min invention on one case, then the definition |
| Procedure | row reduction, Gram-Schmidt, integration by parts, a proof template | Worked example first, then fade |

- Invention works only when it uses what they know, exposes a gap, and the definition is compared with their attempt.
  Cap it at 8 minutes; never let it become floundering.
- Definitions and theorem statements are generated by the student before being shown.
- Fading: full example with a "which principle justifies this step?" prompt, then remove the last step, then the last
  two, then unaided. Withdraw examples once they solve two unaided problems on that procedure.
- Interleave: the recall block always carries one problem from an older section, unlabelled.
- Successive relearning: a card or problem counts as learned after three correct recalls, then relearn at widely spaced
  later sessions; more than three relearnings is not worth the time.

## Payoff

Name the ML or applied use in one sentence (state 7), as content. Never supply motivation
yourself: have the student write why the topic matters to them;
told utility value lowers interest in low-confidence learners.

## Hint ladder

Enter every problem at rung 0 and let their response set the rung. One rung per failed attempt, never skip upward.

| Rung | Type | Shape |
|---|---|---|
| 0 | Entry | "What is the unknown? What are the data? What is the condition?" |
| 1 | Pointing | Direct attention to a feature, no method |
| 2 | Structural question | Name the kind of statement involved and ask which equation or object it concerns |
| 3 | Teaching | State the principle that applies |
| 4 | Worked analogue | Solve fully a different, smaller instance, then "now do yours" |
| 5 | Bottom-out | Give the step, then demand the same argument on an isomorphic problem, closed-book |

Give the answer outright only when all hold: they have produced something; the failure is a missing prerequisite or a
notation confusion (told immediately), not a conceptual gap (never told, refined against a failing case); rung 4 was
reached and failed; an impasse past about ten minutes. Otherwise defer the theorem, build the missing piece, return
tomorrow.

## Error taxonomy

Errors are rule-governed; find the rule. The first stage they fail (reading, comprehension, method choice, process,
writing the answer) is the stage that broke.

| Type | Signature | Response |
|---|---|---|
| Slip | Wrong once, right elsewhere, they spot it on reread | "Check that line again." Say nothing more; count it |
| Procedural bug | Same wrong step recurs, consistently | Name the buggy rule; have the student run it where it fails |
| Misconception | Wrong procedure chosen; confident wrong T/F | Get their definition; show where it holds, then breaks |
| Missing prerequisite | Errors cluster on one earlier idea | Stop; take the prerequisite branch |
| Notation | Misreads the question: a set for a matrix, a vector for its set, rows for columns | Fix the notation only |
| Method choice | Understands the words, cannot pick a tool | Point at the section's theorem list, not the theorem |

Only misconceptions and prerequisite gaps enter the log with a tag. Slips are counted; three within ten minutes is a
fatigue signal, not a knowledge signal.

## Prerequisite chain and back-up rule

Most failures on an item are failures on an earlier one, so diagnose downward first. Build the chain from the book's
own dependency order. Function notation (`T : R^n -> R^m` as a mapping) is a prerequisite adults have often lost; check
it explicitly.

Declare the back-up aloud ("this isn't X, it is the node below it; we back up one"), run three drills on that node, and
return to the original exercise unchanged. Drill failed: back up one more, never two at once. Log it as a gap and card
the prerequisite mechanic, not the failed exercise.

## Placement probe

Run once before the first section when no log exists. Twelve minutes, about eight items chosen from the book's
prerequisites, hardest-informative first; stop a branch at the first failure and pick the next item from the last
answer. Frame it as a map, not a grade. Score each item PASS, SLIP, GAP or MISCONCEPTION, write one knowledge-floor
line into the log, and start at the earliest section carrying a GAP or MISCONCEPTION; passed sections get a five-minute
retrieval pass, not a re-teach.

## Fatigue

Fatigue degrades error-checking before execution, so a tired student corrects mistakes less often; that is why tired
sessions are retrieval only. Speak of fatigue and checking, never of a depleted tank. Track returns, not streaks:
missing once is an accident, missing twice starts a new habit.
